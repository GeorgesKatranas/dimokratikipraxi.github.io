# Δημοκρατική Πράξη

Ιστολόγιο κοινωνικής και πολιτικής ανάλυσης με έμφαση
στη θεσμική λογοδοσία, τη δημοκρατική συμμετοχή και τους συνεταιρισμούς.

## Θεματικές
- Δημοκρατία
- Κοινωνία
- Συνεταιρισμοί
- Οικονομία
- Προτάσεις Πολιτικής
- Ανακοινώσεις

## Στόχος
Παραγωγή τεκμηριωμένων προτάσεων και ενίσχυση του δημόσιου διαλόγου.
